# Security Policy

## Supported Versions

Security fixes are applied to the latest code on `main`.

## Reporting a Vulnerability

Do not open public issues for security vulnerabilities.

Report privately with:
- vulnerability description
- affected version/commit
- reproduction steps
- impact assessment
- suggested mitigation (if available)

If private reporting infrastructure is not yet configured for this repository, contact the maintainers directly and request a private channel before disclosure.

## Response Targets

- Initial acknowledgement: within 3 business days
- Triage decision: within 7 business days
- Fix or mitigation plan: based on severity and complexity
